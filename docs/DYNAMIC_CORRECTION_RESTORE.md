# 跨周波动态纠错：恢复与统一特征验证

2026-10-29完成。**旧算法原样重拟合与旧C0预测完全一致；固定36维版本恢复到相近指标量级。**
这是现有冻结骨干和分组外预测上的方法恢复，不是新增采集的独立确认。

## 方法与统一输入

两频带10–100kHz、100–400kHz的活动在20个相位箱中表示。
分别比较当前周波与过去1、2、4、8个周波的分布余弦相似度、MAD、JS散度、峰值变化，
形成32个动态统计，加4个历史可用性标记。所有模型、所有数据集使用同一36列和相同算法。

原骨干内部不改动，输出经训练协议规定的变换得到原故障分数；动态线性残差与训练正常空间距离权重
共同形成校正。可信度来自动态分布距离，不是PLL锁定概率。

三个版本：

- `legacy_refit`：训练内筛到最多24列，按旧流程重拟合，检查算法复现。
- `uniform36`：固定全部36列，三个模型共用，无列选择。
- `dynamic32`：固定32个动态统计，去掉4个历史可用性标记。

均复用相同骨干/三内折分组外预测，并在外训练内拟合标准化、PCA、残差与融合参数。
三个种子、五外折、两个数据集、三个骨干，共90组、540次初始/最终小型纠错头拟合。
只使用物理GPU1、2、3。

## 结果：三种子均值条件等权周波BAcc

| 数据集 | 模型 | 原骨干 | 旧C0 | 固定36维 | 去标记32维 |
|---|---|---:|---:|---:|---:|
| 自采5 m | ArcFENet | 85.400% | 86.220% | 86.324% | 86.424% |
| 自采5 m | HYDRA | 87.889% | 89.849% | 89.664% | 89.700% |
| 自采5 m | ArcFusionNet | 89.600% | 90.299% | 90.068% | 90.165% |
| 公共数据 | ArcFENet | 81.647% | 87.633% | 90.262% | 88.568% |
| 公共数据 | HYDRA | 88.833% | 95.260% | 95.468% | 94.956% |
| 公共数据 | ArcFusionNet | 76.693% | 92.342% | 92.764% | 92.363% |

`legacy_refit`在所有组逐预测复现旧C0，因此表中省略重复列。固定36维相对旧版四组合均值更高；
自采HYDRA/Fusion分别低0.185/0.231pp。它是相近指标量级的恢复，不是六组合全面超过或正式等效。

固定36维相对原骨干六组均值正向；其12项主比较经Holm校正后均未通过0.05阈值。
全部配对区间与原始p值保留在本地报告，不把点估计提升写成统一显著收益。

去掉显式历史标记后仍保留明显均值增益，说明高分并非完全依赖这些标记；
公共数据32维低于36维，也不能宣称标记无作用。动态信息和记录进程线索尚需进一步区分。
本轮未单独验证同步坐标相对固定20ms、相同历史和同一纠错器的独立优势。

## 独立模块接口

实现：`src/arc_model/methods/dynamic_correction.py`、`dynamic_score_module.py`。

```python
from arc_model.methods.dynamic_score_module import DynamicScoreModule

module = DynamicScoreModule.load("/absolute/path/to/uniform36_module.npz")
# base_logit必须保持训练时原分数变换协议；dynamic36为[N,36]。
corrected_probability = module.predict(base_logit, dynamic36)
baseline_probability = module.predict(base_logit, enabled=False)
```

原实验将原概率按1e-7数值下限截断后转换为logit，调用者需保留相同协议，
不能直接以未校准的任意分数替换。关闭模块返回给定logit的sigmoid。
导出包保存训练内距离分位阈值，推理无需训练样本；动态特征仍需要严格过去的周波。
这套接口是分数级可插拔纠错，区别于静态8维分类前拼接与纯输入前端。
