# 变更记录

## 2026-10-29：模型独立化与输入前端快速验证

### 用户目标

将电流自同步定义为输入表征前端，辅助特征分支作为独立候选；三个模型代码和数据加载器分别独立，便于逐个检查。只使用物理GPU1、2、3进行训练。

### 结构改动

- 新增`models/standalone/arc_fenet.py`：内置HFDC、DDC、骨干及原分类头。
- 新增`models/standalone/arc_fusion.py`：内置时域块、谱分支、Transformer和交叉注意力。
- 新增`models/standalone/hydra.py`：内置随机卷积、SparseScaler及线性头，保留来源署名。
- 新增三个专用加载器，各自读取对应模型输入、校验元数据及组隔离，不引用通用加载器。
- 模型工厂及HYDRA现有特征入口改用独立文件；原实现保留用于一致性回归。
- 新增`methods/phase_representation/input_frontend.py`：无学习参数的低频电流与两频带能量序列化候选，输出1000点输入，不新增网络分支。
- `PhaseFeatureAdapter`保留为明确的辅助分支候选，不默认接入本轮四组实验。

### 实验与记录

本地`outputs/input_frontend_pilot_20261029`保存冻结协议、源文件哈希、分折权重、标准化状态、OOF预测、配对区间、日志和核验结果。该目录不会上传原始数据或标签到GitHub。

两数据集×四输入组×五折×一个种子，共40次HYDRA拟合。训练预算相同，每个分类器898个参数。主指标为条件等权周波BAcc。边界保护和组划分沿用经审核的连续数据协议，不使用旧裁剪数据。

本轮发现：自同步电流相对固定窗均值提高；低高频序列化对公共数据有明显收益，但自采数据上低于自同步电流。因此未将该序列化方案确立为统一默认前端，未扩大为三个骨干的大矩阵。

### 验证范围

22项模块测试通过，包括独立模型前向/梯度一致性、HYDRA变换一致性、加载器隔离和前端输入契约。GPU随机变换与CPU误差已检查。分类结果另用保存权重和训练内标准化状态重放核验，具体状态见本地`audit/PASS.json`。

### 保留与限制

不覆盖历史权重、不删除不利结果、不变更标签、不将单种子快速试验写成确认性结论。既有C0成绩不能继承为新输入前端的效果。模型独立化未改动网络数学结构；新增输入候选是另一个实验变量。
