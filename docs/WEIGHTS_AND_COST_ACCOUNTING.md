# 直接模型中的加权与成本口径

这里的“权重”有不同含义，不能统一称为可信度或融合权重。

## 1. 网络连接权重：卷积和全连接

卷积/全连接执行$y_j=\sum_i W_{ji}x_i+b_j$。$W$和可用偏置均由训练集反向传播学习，用于提取判别模式，不代表某个样本可信或某种模型更好。每个存储的$W_{ji}$属于参数；一次$W_{ji}x_i$及其累加记为一个MAC。

在真正的事件SNN中$x_i\in\{0,1\}$，面向事件执行可将一次有效的$W_{ji}\times1$视为加权累加AC；但当前GPU卷积仍稠密执行。不能把稀疏等效AC从稠密MAC中再减一次，也不能把AC计数直接换成实测能量。

BN的$\gamma,\beta$是可学习仿射参数；推理均值/方差仅来自训练集。它们与网络参数一并统计，但BN、激活、池化、编解码与内存访问不计入“加权层MAC”主列，而是另列/明确未包括。

## 2. 训练样本权重：条件与类别均衡

外训练折有$G$个条件组，总窗口数$N$，每组都有两类，组$g$类别$c$的数量为$n_{g,c}$。样本$i$的权重为

$$w_i=\frac{N}{2G\,n_{g_i,c_i}},\qquad \frac1N\sum_i w_i=1.$$

其训练目标为

$$\mathcal L=\frac1N\sum_i w_i\operatorname{BCE}(y_i,\sigma(z_i))+\lambda\mathcal R_{\rm activity},\qquad\lambda=0.001.$$

小批量采用对应加权均值。它防止长录波或数量多的一类支配梯度；只根据训练折组和标签确定，不读测试标签。$w_i$不送入推理，也不是新增可学习参数。历史输入标准化仍用训练折当前周波的逐通道统计，不把样本权重偷偷用于归一化。

纯连续CNN没有脉冲活动项（返回0）；混合和全SNN的活动项定义随结构不同，因此结构效率比较不能声称只单独改变了脉冲神经元。隔离脉冲机制的同编码连续主干对照另由phase_event_raw试验完成。

评价的“条件等权BAcc”也不是上面的训练样本权重：先在每条件计算$\mathrm{BAcc}_g=(\mathrm{TPR}_g+\mathrm{TNR}_g)/2$，再对组平均。池化Acc/Recall/FPR/F1/AP仍使用逐窗口预测，不能混用权重后反推混淆矩阵。

## 3. RCR拟合权重：参考估计而非分类

因果参考窗口内的近期权重为$r_i=\exp((t_i-t_{\rm end})/0.03)$。鲁棒迭代根据残差$e_i$、尺度$s$计算Huber型权重$h_i=\min(1,1.5s/\max(|e_i|,\epsilon))$；加权最小二乘使用$r_i h_i$拟合直流项及1–9次谐波基。

近期权重提高最近样本对当前端点估计的作用；残差权重降低异常样本影响。二者均是算法规则，不由分类标签学习，不代表异常一定来自电弧，也可能是正常负载瞬态。

参考相位更新系数为$\alpha=(1-\exp(-\Delta t/0.004))q$，$q=\operatorname{clip}(1-\rho/0.45,0.1,1)$，$\rho$为参考拟合残差比；相位修正还受最大步进约束。频率更新另用80ms时间常数。此处$q$只控制参考更新，不是旧C0/B1方案的分类分数门控。本轮直接网络没有$z+\alpha qr$式分数融合。

## 4. 相位箱强度与分布

每个相位箱的平均平方强度是原始带通电流平方的时间积分除以箱长：$E_b=(1/\Delta t_b)\int_b i_H^2(t)dt$。均匀采样时可用样本平方均值实现，边界由相位决定；采样率不同不能直接比较未除时长/未归一化的求和。

$p_b=E_b/\sum_jE_j$是等相位箱**强度归一化分布**，并非电气有功功率占比；只有单点电流，没有用同步电压计算真实电能。$\Delta p_b=p_{k,b}-p_{k-1,b}$才描述相应位置的跨周波变化。输入中的log量也不是新权重。

## 5. SNN状态系数与读出

泄漏$\beta=\sigma(a)$与阈值$\vartheta=\operatorname{softplus}(b)+0.05$逐神经元可学习并计入参数。它们控制膜电位记忆和发放，不代表样本可靠性。二值事件编码的死区0.25、饱和3、四个仿真步为固定配置，不从外测试拟合。

全事件SNN对当前周波四步的线性读出取等权$1/4$均值；这是固定平均，不是注意力。直接CNN–SNN候选的迹变量使用固定$0.8/0.2$递推，读出连续膜电位/阈值加迹；因此它是混合网络，不宣称所有矩阵由脉冲驱动。

## 6. 紧凑CNN的历史读出权重

紧凑CNN有9个可学习标量$a_1,\ldots,a_9$，初始全部0。对可用历史掩码$m_k$计算

$$\omega_k=\frac{m_k\exp(a_k)}{\sum_j m_j\exp(a_j)},\qquad h=\sum_k\omega_k h_k.$$

9个参数由训练BCE共同学习，含在总参数里。它是**固定滞后位置的可学习汇总**，不是逐样本内容注意力；推理只随有效历史掩码改变，不能称为动态可信度融合。权重作用于当前9周波内隐藏特征，不作用于多个模型的最终概率。它也未单独做部件必要性消融，不作为本轮创新声明。

## 7. 必须分开的成本

1. 参数：可训练/总参数、FP32权重bytes、BN等缓冲bytes。
2. 加权MAC：每个完整9周波输入一次预测的所有卷积/全连接，包含重复计算历史；1MAC不是1FLOP，通常乘和加计2FLOPs。
3. 脉冲等效AC：按实际非零事件数计算，适用于潜在稀疏后端；当前GPU实际仍执行稠密算子。
4. 状态与非线性：LIF更新、BN、GELU/sigmoid/softmax、池化/编码等另列，不能假定免费。
5. 原采样率前端：高频带通/平方累计、参考滤波、RCR最小二乘、分箱和缓存；随采样率、参考支持与启动状态变化，不用一个网络MAC数字代替。
6. 实测：CPU/GPU模型延迟、含前端软件FIFO、设备能量/空闲基线。GPU、MCU和神经形态硬件的结论分别成立，不能跨硬件推导。
