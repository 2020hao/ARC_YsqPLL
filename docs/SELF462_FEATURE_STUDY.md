# 462条自采数据：特征分析与CNN–SNN输入验证

本研究仅使用用户新确认的462次人工标注/导出记录，4类目标负载，背景中的台灯和微波炉保留。检测输入固定为114卡CH0；116支路不输入分类器。此为该自采数据专门研究，公共数据不在本轮范围。历史研究和冻结baseline均保留。

## 分组与样本

CSV纳入清单哈希固定为`2506a6bea05d82107de2e5d2ac4d98d71b501258fe99ec254e07322e8179b201`。按目标负载与排序后的背景名称构建156个组，合并“目标/拉弧”同义目录。每类负载独立打乱组，四折轮转分配；同工况重复录波完全同折。标签先扣除manual_offsets转换到导出BIN坐标。

全部候选计算使用因果滤波；高频在原始2MHz信号上提取。固定窗、SOGI、RCR在共同20ms判决锚点评价，各自仅选择当时已完成且可用的周波，参考不可用时固定窗后备。仅保留三种坐标均有9个连续历史周波、完整历史支持位于同一标注状态内且距离边界至少40ms的样本。该限制针对稳定状态特征分析，不能据此声称起弧检测速度。

人工对齐BIN已基于人工起弧标注裁剪过两卡，故属于离线已对齐采集分析。RCR本身不读取标签，但本轮不能替代未经人工事后对齐的原始流端到端部署验证。

## 40项候选

- 10项时域/低频频谱：log RMS、波峰因子、偏度、峭度、相对差分RMS、相对零电流比例、前后半周能量不对称性、2–10次THD、3次和5次谐波比。频谱使用50kHz抗混叠电流与Hann窗；为周波窗近似谱指标，不等同于标准THD计量。
- 5项频带指标：1–10k、10–100k、100–400k的log平均功率，高频上带占比、中频占比；无物理标定时不称安培平方。
- 16项相位分布与集中性：两个高频带各自的log脉冲集中度、归一化分箱熵、最大分箱占比、0/180度±18度附近分箱能量占比、半周能量不对称性、峰值位置sin/cos、一阶圆周集中度。
- 9项动态：两个高频带各自的相邻周波分布平均绝对差(MAD)、JS散度、余弦距离、峰值位置圆周漂移，以及log RMS周波变化。

分布由64个分箱的平均功率归一化；脉冲集中度为原采样率功率二阶矩与平均功率平方的比值，再取log10。0度定义为估计电流基波相位，不等于电压零点。所有指标的确切实现以版本脚本为准。

## 统计与筛选

按工况计算每项特征的正常/电弧AUC。方向在外层训练工况确定，应用于测试工况；不使用每个测试工况的`max(AUC,1-AUC)`。工况等权汇总，逐负载单独报告。相位效应采用工况配对bootstrap区间与符号翻转检验，对80个比较做Holm校正。

仅在每折训练工况，从预先定义的4个两通道家族中选择至多一个：归一化高频分布、绝对分布差分、脉冲集中度、频带分配。候选需至少有一项对应标量指标在全部目标负载的训练工况AUC>=0.60、超过机会水平的工况比例>=0.70。若没有通过者，不将新增物理信息强行接入。此门槛为预先约定的工程筛选规则，不是已发表标准或特征有效性的充分证明。

## 受控模型验证

保持现有单一CNN–SNN分类器、数值编码、50epoch训练、0.5阈值、条件/类别等权BCE。每折选择独立，仅使用训练标签。7个配置×4折×1种子=28次拟合：固定窗原5通道、RCR原5通道、固定窗选中2通道、RCR选中2通道、RCR同容量重复信息对照，以及RCR逐新增通道移除。

原网络7097参数，增加2输入通道后7257参数。新增入口权重初始化为零，原入口及其余结构保持原初始化函数。移除对照保留同样参数量，对被移除通道置零。指标包括条件等权BAcc、Acc、Precision、Recall、FPR、F1、AP、ROC-AUC及混淆计数。逐工况配对，报告逐负载结果；28个模型均需重载检查点重放。单种子结果是本轮机制筛选证据，不替代最终多种子论文结果。

## 完成状态与输入决策（2026-11-05）

462条记录共同保留125,166个稳定状态锚点（正常61,967、电弧63,199），40个指标及三种坐标分析、28次模型拟合已完成。四个外层训练折均选择两带脉冲集中度，但新增7通道输入未提高原RCR5通道的条件等权BAcc：97.273%→97.086%，差值−0.187 pp，95%工况配对区间[−0.664,+0.249] pp，Holm校正p=1。单变量区分能力不能替代模型增量证据，**默认输入继续保留原5通道**；7通道仅保留为实验候选。
