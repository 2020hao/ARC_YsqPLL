# 训练组折外校准并入单一分类头

公共开发结果的主要缺口已从大量误报转为部分电器的召回不足，同时排序指标较高。该轮检验分类头的跨工况分数尺度，保持原raw数值编码、峰值池化与动态摘要结构，不新增外部纠正分支。

在每个外层训练分区内，按工况/电器组划成两个内层分区。每个样本由未训练过其工况的内层模型产生分数，形成覆盖外训练分区的组外logit。低频/高频输入和动态摘要的统计参数都只由相应内层训练组拟合。

只用这批内层组外分数拟合两种固定输出方案：一个偏置，或正比例缩放加偏置。目标为工况类别等权BCE加偏离恒等的0.01正则；偏置范围−4至4，比例范围0.25至4。外测试标签、分数不参与参数估计或方案选择，原未校准方案同时保留。

将校准直接折入原最终线性层：权重乘比例，原偏置乘比例后再加校准偏置。推理仍是同一个分类器、8,249网络参数、约0.685M模型矩阵MAC，判决阈值0.5。训练阶段另拟合1或2个监督校准系数，折叠后不增加推理层或参数槽位。

两库分别使用完整462条125051窗口、公共1357窗口，原四/五折和3种子。精确复用第二阶段27个外模型，新增54个内层训练模型，两种校准共享同一套组外分数。重载全部内层模型和三版本外模型重放预测。GPU仅物理1/2/3，原始数据、旧模型、基准不变，无蒸馏。

入口`run_experiment_suite.py --suite configs/modules/folded_calibration_20261105.yaml --execute`，本地产物`outputs/folded_calibration_20261105`。这是既有曝光组上的第三轮开发验证，完整保留有利和不利结果，校准不作为新的深度架构贡献或独立SOTA证明。
