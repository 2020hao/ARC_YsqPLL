# Baseline定义与原论文复现状态

2026-10-29更正。用户要求的baseline是**保留论文原方法，不加入本研究改进**。
此前表中的RCR-M0已经使用本研究电流参考与自同步输入，只能作为内部消融参照，
不能命名为“论文原始模型baseline”。所有已冻结数值保留，修正其解释与标签。

## 三种结果分别报告

| 名称 | 定义 | 用途 |
|---|---|---|
| 作者原文报告值 | 作者原数据、划分和指标上的结果 | 文献/复现说明；不直接填入我们的双数据集主表 |
| 论文原方法本地baseline | 原方法在当前两个数据集、相同分组划分和指标下的无改进复现 | 检验本研究完整方法的增益 |
| RCR-M0适配消融 | 已加入本研究RCR输入，但未加入C0/动态36 | 检验动态纠错相对于已同步骨干的增量 |

“无改进”指不加入本研究的RCR、自同步重采样、额外高频/历史输入、C0和可信融合。
作者原方法自带的处理必须保留：ArcFENet的VMD/MBWVD及HFDC/DDC、HYDRA的原预处理
和随机核/分类器、ArcFusionNet原有的相位对齐与差分基准均不是本研究的改进。
