# 冻结基线上的双分支与输入模块验证

本轮先开展固定seed0、五折、两个数据集、三个模型的可行性验证。它使用冻结基线中
相同seed0的预测进行配对，不拿新单种子成绩与旧三种子均值计算增量。当前外折已经
经历多轮探索；结果属于探索性证据，不作为全新盲测。完整协议为
`configs/modules/locked_routes_20261030.yaml`。

## 要回答的问题

1. 在已锁定的无研究增强比较器上，跨周波动态分支是否仍有补充价值？
2. 相同两频带、历史跨度、36维统计和残差头下，RCR坐标是否优于固定20ms坐标？
3. 不增加辅助支路，仅改变模型现有输入，是否可以直接切换？是否必须重新训练？

## 最小对照矩阵

| 版本 | 骨干权重 | 模型输入 | 新增动态支路 | 目的 |
|---|---|---|---|---|
| baseline | 冻结seed0 | 固定20ms | 无 | 共同参照 |
| calibration_only | 冻结seed0 | 固定20ms | 无，仅正斜率仿射分数校准 | 排除仅校准带来的收益 |
| dual_fixed20 | 冻结seed0 | 固定20ms | 固定窗36维 | 同信息、同容量对照 |
| dual_rcr | 冻结seed0 | 固定20ms | RCR坐标36维 | 检验相位组织的额外价值 |
| single_direct | 冻结seed0 | RCR对齐；无效时固定窗 | 无 | 无需重训的输入热插拔 |
| single_retrained | 相同结构、完整预算重新拟合 | 同上 | 无 | 需要输入适应的前端方案 |

双分支不同时改动骨干输入，避免把输入变化和分数纠错混成一个变量。后续若组合
两者，应另立实验，不能直接把本轮两条路线的收益相加。

## 输入和特征

低频5kHz电流只用于恢复参考坐标。ArcFENet保持250kHz、5000点、原500次VMD/
MBWVD；HYDRA先在1/2MHz原始电流上整流，再因果抗混叠至50kHz、1000点，采用
作者FD的1024维固定变换；Fusion-current保持12.5kHz、250点时域及训练内RF32频域。
这里没有将三个骨干都改为5kHz输入。高频动态分别从原生采样率下的10–100kHz和
100–400kHz活动提取，再按20个相位箱/时间箱组织。

固定36维为两频带×四个历史间隔（1、2、4、8周波）×四统计量（余弦、MAD、JS、
峰值相对变化）共32维，加四个历史可用性标记。三个模型使用同一集合，不按测试
电器筛列。历史只向过去取，且不能跨原始采集/参考重启边界。

## 拟合和泄漏控制

原父基线权重全部复用。双分支的最终残差和正斜率仿射校准使用外层训练集上的
诚实两内折OOF分数。调门控时，选择一个内折基模的完全未见组，再拆为残差拟合组
和门控选择组；不能让该基模训练过门控验证组。最终外测仅计算指标。

已有Fusion诚实内折模型经身份检查后复用；另外补齐ArcFENet与HYDRA内折。单模块
重训仍执行ArcFENet20轮、Fusion70轮和HYDRA原L1-hinge目标，不用缩短训练换速度。
GPU仅用物理1、2、3；0保留。CPU线程受限，输入缓存复用要有来源及配置指纹。

## 热插拔的验收边界

- 开关关闭必须逐值恢复同一权重的原始前向；并验证输入、分数、判决一致。
- 直接插件使用冻结权重与训练内预处理状态，插入时不重新训练、不增加网络支路。
- 重训插件不增加结构参数，但它的权重已改变；关闭输入插件不代表恢复旧基线成绩。
- 参考无效时所有方法按同样规则后备，不通过删除困难周期提高指标。有效/后备分层
  报告，主表保持全部38,374/1,361个审核窗口。
- 参数不变不等于端到端更快。已有离线缓存不代表线上前端零成本，预处理与模型调用
  成本应分别记录，未经实测不声称整体轻量化。

## 结果与判定

完成后统一从逐窗预测重算BAcc、Accuracy、Precision、Recall、F1、Specificity、FPR、
AUC/AP、MCC和整数混淆矩阵。按条件/电器文件计算配对区间，不能将周波视为独立
重复。六个数据集×模型组合分别保留正向、负向和不确定结果。

结果保存在本地`outputs/locked_routes_20261030/`。运行前的状态、实际完成数与审计
记录决定是否完成，不以已存在的候选模型目录或历史C0表代替本轮实验。

## 复查与运行入口

在项目根目录运行预检，不会重复启动已有实验：

```bash
CUDA_VISIBLE_DEVICES='' python scripts/check_baseline_release.py
CUDA_VISIBLE_DEVICES='' python scripts/run_experiment_suite.py \
  --suite configs/modules/locked_routes_20261030.yaml
```

需要执行时追加`--execute`；已有同研究进程时只报告状态，避免重复占卡。新运行需
先备齐两个审核队列与注册的冻结父状态。训练分阶段日志、状态和输出放入协议指定
目录。代码与数据身份不匹配时停止检查，不以重新随机划分替代缺失输入。

双分支推理加载各自`dual_rcr_state.npz`，它含标准化、PCA距离、残差系数、门控阈值
和仿射校准。模型权重与模块状态分别保存，可以开关；关闭跳过整个校准和残差。
例如ArcFENet（`x_fixed`是原100×100 RGB，`dynamic36`按因果历史顺序提取）：

```python
import numpy as np
import torch
from arc_model.implementations.dual_arc_fenet.model import Model

net = Model(extra=0).eval()
net.load_state_dict(torch.load(parent_weight_path, map_location='cpu', weights_only=True))
state = dict(np.load(correction_path))
calibration = dict(slope=float(state['calibration_slope']),
                   intercept=float(state['calibration_intercept']),
                   fit_indices=state['calibration_fit_indices'])
net.attach_correction(state, calibration=calibration)
with torch.no_grad():
    original = net(x_fixed, enabled=False)
    corrected = net(x_fixed, dynamic=dynamic36, enabled=True)
```

这是分数纠错热插拔接口。纯输入插件另用`plugin_*`目录，传入对齐后的原接口张量
和逐窗布尔`available`掩码，不加载动态残差、不增加特征分支。两个接口的性能分开
验证，不能仅因都能开关就互换其证据。
