# 动态信息保留的自有CNN–SNN

本轮是自有模型的独立直接分类实验，保持RCR→原五通道→CNN–SNN→单分类器，不使用外部baseline分数、蒸馏或最终分数纠正。旧三基准源码和所有历史结果保留。

## 问题与改动

既往公共结果中的跨电器失败包括高AUC但分数阈值失配，以及个别种子反向排序。原输入中包含对应位置的分布变化；当前两次平均池化与最后膜状态读出可能使这些变化难以被学习。已有单变量分析仅解释现象，不作为本轮测试电器专属规则。

从同一九周波、同一双频带log10功率重新构造活动份额，比较1、2、4、8周波历史的余弦相似度、平均绝对差、JS散度与对称峰箱份额变化。32个连续量加4个历史标记，直接进入同一个最终分类器。均值/尺度仅用外训练工况估计，历史缺失在标准化后仍保持0；标记保留二值。

四个预定配置：

| 配置 | 参数 | 唯一改变 |
|---|---:|---|
| 原状态读出 | 7,097 | 原五通道CNN–SNN |
| 状态＋动态摘要 | 8,249 | 128状态＋36摘要进入32维隐藏层，新增列0初始化 |
| 更大读出容量 | 8,285 | 隐藏层32增至41，无新信息，略大容量对照 |
| 峰值池化＋动态摘要 | 8,249 | 在动态版上只将两次平均池化替换最大池化 |

局部峰值保留与分层信息处理参考SpikingResformer（CVPR2024）等原论文的结构动机，不移植其视觉任务性能或声称本模型为该模型复现。参考入口写入本地协议。

## 数据与训练

完整462次自采使用原生2MHz的既有相位输入，125,051共同窗口、156工况、四折。公共使用原生1MHz前五通道、1,357窗口、13录波组、五折。自采不因1MHz既有成绩略高而更换原生主输入。两库独立训练。

每配置3种子；共108个外折模型状态，19个原参照可在索引/训练统计/检查点逐项匹配后复用，预计89次新拟合。这里是4种方案，折与种子是评价重复，不是108种候选。保持50epoch、batch512、AdamW lr0.001、工况类别均衡BCE、原脉冲惩罚、最终epoch和阈值0.5。

预先固定三个比较：动态−原模型、动态−容量对照、峰值动态−平均池化动态。两个数据集共6个主比较，按工况/电器录波组配对和多重校正。报告全部指标、逐电器、逐种子、参数与计算范围，不选最佳种子为最终结果。

## 执行与记录

入口：`scripts/run_experiment_suite.py --suite configs/modules/dynamic_state_20261105.yaml --execute`。只使用物理GPU1/2/3，GPU0禁止。原始录波和标签不重新生成；可复用缓存只改变读取效率，不引入训练或测试信息。

输出为本地`outputs/dynamic_state_20261105`。训练前冻结数据、划分、组件和配置哈希。完成后对全部保存预测重放，复核摘要缓存与即时计算；最后检查原三基准源码未变化。历史公共数据已多次用于开发，本轮按开发实验解释，SOTA需要额外同协议强模型和独立证据。
