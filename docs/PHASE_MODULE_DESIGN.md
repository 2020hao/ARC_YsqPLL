# 电流自同步相位表征模块：候选v1

状态：候选实现和接口验证，不是分类性能结论。模块不使用C2、类别或未来样本估计相位。

## 边界与输入输出

`CurrentRecording`读取原生电流、采样率、记录时间原点；NET9770头部采样率及文件大小必须匹配，C3时间间隔必须与1MHz相符。标签审核独立于表征模块，未标注不等于正常。

`current_reference`仅提供固定窗/SOGI/RCR/CFT接口，调用原有算法，不重写冻结内核。RCR/CFT为最后已观察样本时间戳。SOGI使用原5kHz内核；相位窗口接口直接使用5kHz时钟节点，与历史50kHz外推后的SOGI边界可能有差异，不能宣称全部窗口与历史字节相同。

`prepare_phase_windows`维护原生周波与固定20ms后备两个候选序列。决策时仅取已完成、参考已可用且属于当前有效段/epoch的周波。原始高频带通能量按相位边界积分；不从5kHz恢复高频。检查线性插值右侧采样时刻未超过决策锚点。

当前原生250kHz支路保持既有112.5kHz FIR策略。112kHz附近衰减是已知适配限制，不在本次结构重构中偷偷改变。低频输入50kHz、参考5kHz与两条原生HF路径分别保留。

## 10维固定候选

两频带各自总能量取自然对数，另分别计算：0°/180°±18°能量占比、前后半周能量绝对差占比、二阶圆周矩的cos/sin分量。相位箱20个，中心9°/27°/…；二阶矩对180°极性翻转不变。固定±18°只是待验证的首轮定义，不是已经优化的阈值。

`phase_free`使用同维度的熵、峰值比例、一/二阶圆周集中度，保留同样两个总能量；是普通统计对照，不称完全相同信息。`shifted`对每个周波独立循环移位后提取相同位置特征，强度和各箱能量数值保留；训练和测试都按冻结种子生成控制，不仅在测试时扰动。

原有C0的36维/最多24列动态分支保持原样。v1不引入历史，也不继承C0的分类增益。这使第一阶段可以隔离周期内位置的作用；后续历史模块必须另行版本化和验证。

## 有效性与标准化

`valid[N,10]`描述数值能量是否足够；`phase_valid[N]`描述是否用了原生有效参考。两个掩码不混用。固定20ms控制的特征在数值上仍可计算，不能因为不是PLL周波就自动置零，使对照失效。

`PhaseFeatureScaler.fit`仅接受显式训练索引，忽略各列无效值拟合均值/方差。保存列名、均值/尺度、拟合索引；测试只transform。数值能量floor不是传感器噪声标定。是否只在共同有效周波比较、是否屏蔽后备特征，由冻结实验协议决定，不能看测试分数决定。

## 三骨干接口

`PhaseFeatureAdapter`复制传入本地骨干，保留原始forward和参数形状；从分类前的512维FENet表征、64维Fusion融合表征、HYDRA核特征提取输入。10维候选通过10→16线性/GELU编码，与骨干表征拼接，再由线性头分类。

融合头原表征列复制基线分类器权重，附加列为零。保留但冻结的旧分类头仅用于关闭/后备路径。所有参数、冻结存储和前端成本都应计入报告，不能将初始化零附加列说成参数为零。调用者原模型不会被修改。

模型需要重训；该适配器不是不训练就能迁移的权重，也不是替换原网络内部模块的轻量化证据。现有FENet/Fusion原模型文件不改动；HYDRA的作者最优预处理与本地适配差异仍需独立补强。

## 对照与判断

A固定20ms骨干；B自同步骨干；C自同步+同维度相位无关统计；D自同步+10维候选；E自同步骨干+固定20ms统计；F相同自同步骨干/窗口+逐周期错位统计。

B−A检验波形组织，D−C检验相位表征相对普通信息融合，D−E检验完整坐标/支持流程，D−F检验位置关系。E的支持区间可能改变，不能称纯坐标单因素。三个特征家族删除后需重训并在训练内部选择，保留负结果。先两个数据集特征检查，再固定候选做三骨干分类；本次不自动启动。

指标为条件等权周波BAcc及Recall/FPR/F1/AP，组级配对区间；不把周波数当独立采集数。标签误差/边界保护一致；历史数据已有开发曝光，结果属探索性，独立新增录波用于确认。
