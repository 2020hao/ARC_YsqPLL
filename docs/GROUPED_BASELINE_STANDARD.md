# 分组基线标准：划分理由、复现审查与后续比较约定

2026-10-29。本文件定义当前连续双数据集的本地实现比较标准。原文作者成绩、交替
窗口复现、分组基线、RCR-M0内部消融各有明确用途，不互相代填。

## 为什么交替窗口不作为主评价

论文研究的问题是：当监测点遇到未见电器/背景条件时，所提出的输入组织与纠错模块
是否仍能识别电弧、减少正常误报。按整份采集/条件分组，直接检验这个问题。

同一连续录波的相邻周波通常共享设备形态、谐波结构、增益和背景状态。将第1窗训练、
第2窗测试，能够检验已经见过该录波/电器的窗口识别，却不能直接回答未见条件泛化。
即使窗口本身不重叠，训练测试样本也具有很强的同源相关性。我们的方法还使用过去
1、2、4、8周波，若交替划分，训练和测试的动态输入还可能共享原始历史支持。

交替协议本身是有定义的作者复现方案，不将作者结果一概判为无效。我们保留它作为
实现能力核验：公共审核窗口交替Accuracy99.7046±0.1809%，作者MAT路径99.3103±0.1790%。
同样677个公共测试窗口，分组模型Accuracy89.8080%，交替为99.7046%；这说明评价
协议显著影响分数。训练组成和规模也不同，该差异不是某个模块的增益。

主表采用分组协议，交替高分放入作者协议复现表。[完整交替协议](HYDRA_ALTERNATING.md)。

## 我们实际怎样划分

1. **固定队列与测量通道。** 自采138份NET9770_114 CH0、5 m总路连续电流，原始2 MHz；
   公共13份C3电流，原始1 MHz。只做正常0/电弧1二分类。公共C2仅用于离线标注。
2. **固定审核范围。** 使用当前人工审核区间与40 ms共同边界保护；保留38,374个自采
   周波（18,359正常、20,015电弧）和1,361个公共周波（797正常、564电弧）。原始时刻
   和标签仍有约1–2周波不确定性；保护针对当前窗口支持，不强制8周波历史全部同类。
3. **先分组，整组入外折。** 自采以“拉弧目标种类×背景组合”为47条件组，同组全部
   采集放入同一外折。公共以电器/连续文件为13组，每折测试2–3个未见电器文件。
   同一文件的正常段与电弧段不会分到训练和测试两边。
4. **固定五折，三模型共用索引。** 每个保留窗口恰好在一个外折测试中出现一次。
   各折训练集就是当前保留集合扣除该折测试集合，不对三个模型分别随机切分。
   自采训练组37–38、测试组9–10；公共训练组10–11、测试组2–3。
5. **训练内确定全部拟合量。** HYDRA Scaler、Fusion的RF32和标准化都只使用当折
   训练数据。基线超参数按公开原文或事先披露的重建选择固定，不用测试F1选阈值。
   增强模块的特征选择、可信度和融合校准同样只能使用训练内划分。
6. **合并五折再计算指标。** 每种子先形成覆盖全部保留窗口的一套OOF预测，再计算
   指标。ArcFENet和Fusion报告三个初始化种子的均值/SD；HYDRA使用作者固定随机
   变换seed0和确定性凸SVM，只有一套基线，不以重复相同求解伪造种子不确定性。

自采目标中136份为热水壶、2份为空气炸锅，47是条件组，不是47种拉弧电器；该队列
主要检验背景组合变化。公共一类电器只有一份录波，未知电器与未知采集条件的作用
不能分开估计。数据绝对位置、逐电器构成和每折正常/电弧数量见[DATASETS](DATASETS.md)。

五折已被多轮探索查看。分组隔离解决同源划分问题，但这些外折仍属于已曝光的探索性
评价，不重新称为未使用过的独立确认集。

## 三个实现的原文符合程度

| 检查项 | ArcFENet论文重建 | HYDRA原文FD配置 | ArcFusionNet-current |
|---|---|---|---|
| 输入尺度 | 20ms、250kHz、5,000点→100×100图 | 20ms、50kHz、1,000点整流 | 20ms、12.5kHz、250点总路电流 |
| 作者核心结构 | VMD K3、MBWVD、HFDC/DDC、16/32/64/128通道CNN | k8/g8/m5/stride1/divisor1、1,024维随机变换与L1-SVM | 时域残差/卷积、频域RF32 CNN、两路Transformer、跨注意力 |
| 原生增强部分 | 保留作者HFDC/DDC；不是我们的模块 | 保留作者SparseScaler与随机竞争核 | 保留作者两路结构；不是新增辅助分支 |
| 训练预算 | 20轮、Adam0.001、batch128、wd1e-5 | 固定lambda0.001，均值hinge＋L1，截距不惩罚 | 70轮、AdamW1e-4→1e-6、batch64 |
| 本地选择 | VMD alpha/tau/停止规则、图像映射、FEM融合；上频带边缘滤波 | 因果抗混叠、HiGHS替代MATLAB SpaRSA、组划分 | Transformer未披露宽度/头数/分词，池化与差分离散、RF/归一化、cosine/weight decay |
| 重要缺口 | 高比例VMD达到500迭代上限，不能声称数值前端已完全还原 | 作者MAT99.31%与作者99.63%接近，非位级原环境复现；稀疏度仍有差异 | 缺供电电压对齐、动态正常差分输入、合成故障适配与完整压缩/部署流程 |
| 可用于什么比较 | 固定版本的本地重建前后比较；严格原文比较需披露并补数值敏感性 | 目前最强的作者配置复现基线 | 统一电流输入下的结构适配前后比较 |
| 名称与审核结论 | **条件通过的重建基线** | **原文配置基线可用** | **仅电流适配基线可用；不是完整原方法** |

ArcFusionNet完整方法用供电电压对齐并构造正常基准差分，而现有资料只有电流。
C2是弧电压，不能替代供电参考。因此无论结构参数量多么接近，当前实现都不能
命名为“ArcFusionNet完整原方法”。本地918,258参数与文中约904,500相差约1.52%，
也不等于证明了所有未披露实现细节一致。

### ArcFENet数值前端的专门审查

在正式保留队列，500次迭代时自采11,936/38,374个窗口收敛，公共892/1,361收敛。
其余约68.9%/34.5%尚未满足本地tol=1e-7判据。原文未披露完整VMD停止规则，不能
把达到上限当成已数值收敛，也不能仅据此断言分类一定失效。

另在**折0训练集**每条件每类别取一个中间位置样本，抽查76个自采、22个公共窗口，
将最大迭代从500改为2,000，仅检查输入稳定性，不选模型、不排除样本、不替换旧图：

| 数值检查 | 自采训练抽查 | 公共训练抽查 |
|---|---:|---:|
| 500次收敛比例 | 23.68% | 77.27% |
| 2,000次收敛比例 | 53.95% | 77.27% |
| 归一化图像余弦相似度中位数 | 0.9953 | 1.0000 |
| 归一化图像余弦相似度最小值 | 0.8502 | 0.9535 |
| 归一化图像RMSE中位数 | 0.00629 | 0 |

多数输入形态较稳定，部分窗口仍有可见数值敏感性，简单增加到2,000次也未使自采
全部收敛。保留固定500次版本可建立可复查的本地处理预算；它不能被称为已证明与
作者VMD完全等价的强复现。112.5kHz抗混叠在112kHz约−4.59dB的边缘衰减也保留
为输入差异。后续若修订滤波或VMD，应同步重算baseline与baseline+模块，建立新版本，
而不是只替换其中一边。

最终中心也并非始终停留在初始敏感频带：自采中间/最高模式中心中位数约0.685/21.72kHz，
公共约5.38/100.07kHz。最高模式落在98–112kHz的比例为自采约0.14%、公共约74.06%。
VMD本来允许自适应移动中心，这一结果可由目标数据谱分布及本地参数共同产生，不能
单独判定为代码错误；但它说明不能声称当前输入始终等价地提取了原文两段敏感频带。
因此FENet-v1是带明确数值限制的本地比较器，不是已核验的作者完整信号链。

## 版本标准与后续比较规则

三个比较器分别命名为：

- `B_FENET_fixed20_v1`：当前固定窗论文重建，不加入本研究PLL/C0/新高频历史。
- `B_HYDRA_FD_fixed20_v1`：整流、原FD核配置、1,024维、L1-SVM。
- `B_FUSION_CURRENT_fixed20_v2`：当前审核训练队列上的固定窗仅电流结构适配。

Fusion-v2只修正旧训练清单比当前多1个窗口的问题，不新增模块。30个外折/种子组合
中6个训练索引完全一致的组合可复用，其余24个按原70轮预算重训；RF和Scaler重新
在正确的训练索引内拟合。旧历史分数不覆盖，新版本单独归档。

每个比较器都保存输入/代码指纹、训练测试索引、预处理状态、权重和OOF预测。
后续`baseline+模块`须使用对应比较器的相同队列、折、标签、训练预算、初始化种子
和判定规则；任何改变均单独记录。旧RCR-M0已包含本研究同步，旧C0也不是新HYDRA
SVM的增强结果，都不能代替这三个无研究增强比较器。

Fusion的旧训练包装器含`base.*`权重命名，新独立模型直接使用其内部键；归档保留
原文件并另存`model_portable.pt`统一命名，仅移除已核验的包装前缀，不改变任何张量。
后续按注册表的`weights_path`加载，避免把命名兼容性误认为网络结构不同。
HYDRA决策分数是hinge margin而非校准概率。若纠错头需要logit/概率，应在训练内
定义校准并加入相同校准对照，不能直接套用旧BCE骨干的C0概率解释。

主指标为条件等权周波BAcc；同时报告Accuracy、Precision、Recall、F1、Specificity、
FPR、ROC-AUC、AP以及逐种子整数混淆矩阵。ROC-AUC/AP衡量排序；SVM用未校准margin。
条件等权BAcc与全周波Recall/Specificity的权重不同，不能直接用后两者反推主BAcc。
种子SD与按条件聚类的区间分别报告，不把周波或种子当成独立采集。

完整方法若额外使用原生高频和多周波历史，其总增益包含这些信息的作用。证明相位
自同步的独立价值时，还须与相同频带、相同历史、相同头容量的固定20ms坐标对照。

### 判定与统计约定

- 正类为电弧1。神经模型softmax概率阈值0.5；HYDRA SVM margin阈值0。没有按测试分数调阈值。
- 同一38,374/1,361队列、五折条件/文件隔离；原始记录、source group和条件均无训练测试交叉。
- BAcc条件、pooled BAcc、Accuracy、Precision、Recall、Specificity、F1/Macro-F1、FPR/FNR、ROC-AUC、AP与MCC均已保存。
- `seed_metrics.csv`与`confusion_per_seed.csv`保存各种子完整指标和整数TP/FP/TN/FN；不把三种子重复预测当作三倍样本。
- `bacc_condition_intervals.csv`保存先平均种子、再按条件聚类重采样的描述区间；不将窗口视为独立采集。
- SVM原始margin未做跨折概率校准，AUC/AP与固定阈值指标分别解读。

### 注册与检查

注册表包含70个外折拟合：FENet30、HYDRA10、Fusion30。FENet/HYDRA复用先前已核验状态；
Fusion6个索引完全一致组合复用、24个受旧多余训练窗口影响的组合重新拟合。
Fusion30份权重完整测试重放最大概率误差0、判定变化0；所有当前训练/测试索引与同一队列完全一致。
注册表`baseline_registry.json`中的`weights_path`、权重SHA、索引SHA与预测SHA为后续比较的准据。
任何前处理、数据范围或基线代码变更都另建版本，同步评估baseline和baseline+模块。
