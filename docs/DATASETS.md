# 当前数据集与评价协议

更新日期：2026-11-06。当前训练、评价与论文只使用**462条人工复核自采录波**和**公共Zenodo 5501527**。旧自采队列退出当前实验及主结果，原始文件、冻结模型和历史结果继续保存，供来源追溯。

本文件区分原始录波、评价窗口与统计分组。一个窗口产生一个判定；多个相邻窗口来自同一次采集，不能作为独立采集样本统计。两个数据集分别训练、拟合预处理并报告结果。

### 2.2 标签与输入

人工复核标签包含起弧和熄弧边界，先按人工导出偏移转换到对应BIN时间坐标，再生成窗口标签。检测器只使用114设备CH0总路电流；116设备支路信号不作为分类输入。

按现有标签和实际文件时长统计，不将全部录波统一描述为“大于5秒”或“电弧段均为2秒”。人工边界存在周波级不确定性，评价使用既定40 ms边界保护及共同输入支持检查。标签处理、保留索引和窗口元数据必须随协议保存；不能用检测结果反向修改人工标签。

当前主模型以九周波相位组织输入判定当前周波。历史按因果时间顺序、同记录及参考连续性组织，不允许使用未来电流或测试标签建立历史状态。稳定窗口的分类成绩不能直接换算为起弧检测时延或长期误报警次数。

### 2.4 原生2 MHz与1 MHz比较

当前增强CNN–SNN主输入使用原生2 MHz电流形成的表征。另已完成1 MHz数字适配研究：使用103抽头Kaiser因果抗混叠FIR，通带400 kHz、阻带500 kHz，二倍下采样，群延迟25.5 μs，不提前补偿。该研究不是另一套硬件采集，也不改变462条原始记录身份。

1 MHz比较采用seed0，包含三个冻结基准、1 MHz原五通道CNN–SNN及同结构2 MHz匹配重训，共20个最终模型。当前增强模型研究为原生2 MHz、三种子；两个研究分别报告。[基准复现说明](SELF462_1MHZ_BASELINES.md)记录模型、求解器和预算。

## 4. 窗口、特征与训练内处理

基准模型使用自己的固定20 ms输入适配；相位方法按参考坐标组织完整周波。共同输出锚点不代表两种方法的原始支持完全相同，必须共同检查标签边界。

当前自有模型输入为9周波×5通道×64相位箱，包含低频电流形态、10–100 kHz和100–400 kHz的对数强度，以及两频带分布变化。动态摘要使用1、2、4、8周波历史的余弦相似度、平均绝对差、JS散度、对称峰箱份额变化与历史可用标记。5 kHz只用于PLL参考，高频活动在原生高采样率电流上计算。

标准化、动态摘要统计、特征选择、PCA或校准只在相应训练组内拟合。当前末层校准使用外训练组内二折组外分数，外测试标签不参与系数估计。神经模型阈值0.5，HYDRA margin阈值0；比较时保留训练预算、上下文和预处理差异。

同462条原始录波的特征探索曾使用125,166个稳定窗口。该子研究与当前125,051窗口的筛选协议不同，只用于明确标注的探索分析，不能将其成绩直接移入当前模型表。[特征研究说明](SELF462_FEATURE_STUDY.md)保留来源和口径。

## 5. 指标、统计与证据范围

主指标为组等权BAcc：先在每个工况/电器组计算Recall与Specificity的均值，再对组等权平均。其余报告全部保留窗口的Acc、Precision、Recall、Specificity、FPR、FNR、F1、Macro-F1、AP、ROC-AUC、MCC及TP/FP/TN/FN。

组等权BAcc与池化指标权重不同，不能用池化Recall和Specificity反算主指标。AP采用average precision定义。种子标准差反映训练变化，配对区间以工况/电器录波组重采样，避免将相邻窗口当作独立重复。

现有组已经多轮用于开发，当前结果为分组开发验证；独立确认需要新增或重新锁定的评价协议。462条数据上的三个基准已完成1 MHz比较，三基准的动态旁路仍需同队列验证。
