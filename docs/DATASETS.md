# 当前论文的数据集与评价协议

本说明对应2026-10-29冻结的连续录波队列。两个数据集分别训练、分别评价；任务均为
正常（0）与电弧（1）的二分类。旧的裁剪片段队列与作者后续MAT包不计为额外独立数据。
以下“样本”指输出一个判定的周波/窗口，独立采集单位是原始录波，统计聚类单位是条件组。

## 标签、窗口与采样率适配

自采采用人工审查的正常/电弧时间区间，起止边界仍有约1–2周波误差。公共数据沿用作者
实验状态定义，以C2弧两端电压辅助核验，再使用审核后的区间索引提取C3电流。
**C2仅参与离线标注，不进入检测器，也不是可用于供电相位对齐的电源电压。**
当前共同评价掩码对候选前端的完整输入支持执行40 ms边界保护，且保留原审核排除项。
这里指各前端当前输出窗口支持的联合范围，不要求过去8周波历史全部保持同一状态；
历史按因果、同记录和同参考连续段取用，可跨越故障起止。
保护降低边界不确定性的影响，不意味着建立了采样点级准确真值。1,364个公共候选锚点
本身已经是审核后的候选范围，不能将总65 s录波推算出的全部窗口视为已评价。

固定窗baseline采用20 ms；自同步方法使用估计相位形成的完整参考周波，实际时长随频率
变化，启动/失锁后备窗口另有标识。所有版本使用共同输出时间锚点，但边界与原始支持
范围可能不同，不描述成完全相同的一段信号。每份原始录波可产生多个窗口；增强方法
还使用同记录、同参考连续段内过去1/2/4/8周波的信息，属于**周波级输出、多周波上下文**。

两个原始采样率分别处理，不将数据混合后统一训练。模型输入遵循其本地复现接口：
ArcFENet为250 kHz/5,000点VMD–MBWVD图；HYDRA原文配置为50 kHz/1,000点整流信号；
ArcFusionNet电流适配为12.5 kHz/250点及训练内所选32项FFT。自同步参考可在低采样率
支路计算，高频活动积分仍在2 MHz/1 MHz原生电流上完成，频带为10–100和100–400 kHz。
原始信号采样率高，不表示每个作者模型都设计为直接处理原生MHz序列。

按13个电器/文件组划分，每折测试2–3种未见电器。同一原始文件、采集组以及相同条件的

## 指标与统计单位

主指标为条件等权BAcc：先在每组计算`(Recall + Specificity)/2`，再对条件组等权平均。
同时报告全部保留周波的Recall、FPR、Precision、F1、PR-AUC/AP及TP/FP/TN/FN。
PR-AUC使用average precision（AP）定义。种子SD表示训练变动；配对区间以条件组为
重采样单位，不将相邻周波作为独立重复。连续长期误报警率/事件时延需要完整覆盖与
可靠起弧真值，当前筛选窗口主表不能直接推导这两类指标。

同时补充Accuracy、Specificity、FNR、ROC-AUC、Macro-F1和MCC；公式及完整结果见
[分类指标表](CLASSIFICATION_METRICS.md)。条件等权BAcc和全周波Recall/Specificity
使用不同权重，不能用后两者的平均代替主BAcc。

当前队列已被多轮探索使用，分组隔离解决同源文件泄漏，不能将反复查看的测试折重新
命名为未曝光的独立确认集。
